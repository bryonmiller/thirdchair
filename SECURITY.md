# Security policy

Third Chair is a research simulation. It calls configured language-model endpoints but does not scan targets, execute cyber operations, or contain offensive procedures.

Please report a vulnerability privately to the project author before opening a public issue when the flaw could affect test integrity, expose credentials, or enable code execution. Include the affected version, reproduction steps, expected behavior, and observed behavior.

Do not place real incident data, operational secrets, access tokens, or personal information in a tournament log. API keys are read from environment variables and should never be added to model configuration files.
